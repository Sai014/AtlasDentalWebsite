# Atlas Dental Clinic Website

Frontend-only React site for Atlas Dental Clinic. All content, bookings, and contact forms use local mock data — no API or database required.

## Run locally

```bash
cd frontend
yarn install
yarn start
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
cd frontend
yarn build
```

Static files are written to `frontend/build` and can be hosted on any static host (Vercel, Netlify, GitHub Pages, etc.).
